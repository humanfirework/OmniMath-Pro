### 2. 代码审计修复（8 处）

#### 2a. 高优先级性能修复
**WhiteboardCanvas pointermove 性能优化**
- 文件：`src/components/workbench/whiteboard/WhiteboardCanvas.tsx`
- 问题：pointermove 每次创建新数组 `prev.slice()` + `[...stroke.points]` 导致全量重渲染
- 修复：改用 rAF 批处理，pointermove 时只追加点到 ref，rAF 回调中批量触发一次 React state 更新

**Plot3DScene BillboardLabel 性能优化**
- 文件：`src/components/workbench/plots/Plot3DScene.tsx`
- 问题：`useFrame` 每帧更新所有标签 fontSize（autoRotate 时 60fps × 24 标签 = 1440 次/秒）
- 修复：添加 5% 距离阈值检查，仅在相机距离变化超过 5% 时更新 fontSize

#### 2b. setTimeout 清理（6 处）
| 文件 | 修复方式 |
|------|----------|
| `PreviewPanel.tsx` | useRef + clearTimeout |
| `FormulaRenderer.tsx` | useRef + clearTimeout |
| `FloatingCalculator.tsx` | useRef + clearTimeout |
| `StatusBar.tsx` | useRef + clearTimeout |
| `EditorPanel.tsx` | useRef + clearTimeout + 卸载清理 |
| `AIPanel.tsx` | useRef + clearTimeout |

#### 2c. prefers-reduced-motion 无障碍支持
- 文件：`src/app/globals.css`
- 在文件末尾添加 `@media (prefers-reduced-motion: reduce)` 块，禁用所有 infinite 动画
